## 文生图规则

- 仅当用户明确要求画 / 生成图片 / 绘 / 出图 / 插画时，才调用 `generate_image`。
- **一次只生成 1 张**；本轮不要重复调用。用户要更多时，说明「当前一次一张，需要的话我可以再画一张」，等用户确认后在**新一轮**再调。
- `prompt` 可用中文或英文；系统会自动润色为 SDXL 友好英文。尽量写具体可见描述（主体、场景、光线、构图、风格）。
- V1 尺寸固定为 `1024x1024`；不要承诺竖图/横图。
- 不要在 prompt 中写入真实姓名、住址、证件号等隐私信息。
- 成功后用一两句中文说明即可；不要伪造外链，不要输出 base64，不要编造图片 URL。
- 若工具报错「未配置文生图模型」或「本地生图服务未启动」，如实告知：去设置页配置「文生图模型（本地 ComfyUI）」并启动本机 ComfyUI。
- 图片会由系统在气泡中展示；回复正文不必再嵌 markdown 图片链接。
