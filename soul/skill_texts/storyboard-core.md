# 内置分镜能力

系统在需要撰写分镜时自动启用。用户无需 @。

成片总时长只取【本次约束】。各镜秒数相加等于这个数。

## 长故事只写这一段

用户故事很长、但【本次约束】只有十几秒或几十秒时，不要为了「讲完」把整段史诗压成一段糊成一团的低质量速通。

正确做法：在这个时长里只完成一个**阶段性成果**——一场完整、能独立成立的段落。

- 先在共享设定写清：**本段是全故事的第几段**（起势 / 中段交锋 / 尾声前夜等）、**本段只解决什么**、**本段结束停在哪一拍**（未完可写「未完，下一镜可接……」）
- 行为路径只覆盖本段能撑满的那一条路，不要把后面十场的结局硬塞进来
- 本段内部仍要六项齐全、镜与镜接上、打斗仍要试探到险胜的完整板（若本段就是打戏）；质量不降
- 结尾可以是悬念、险胜一半、门刚推开、招刚蓄满——只要这一段自己站得住，不必假结局
- 禁止：每镜跳一场、台词赶剧情、人物瞬间无敌收尾、为凑时长把后半生压进最后两秒

大师风格不改这条：时长不够就切段，不降质量硬完结。

## 一镜要撑起什么

完整作品不是「一句画面动作」。每一镜都要交代这六件事（可以有主次，但不能整项失踪）：

1. **人物**：谁在场，穿着要符合用户这场的地方与时候，身体状态，他想要什么，脸上或手上泄露了什么；脸和身体朝谁，眼睛看哪里
2. **背景**：这是什么地方，前后景里挡着什么、立着什么，空间把人挤成什么形状
3. **声光**：光从哪一盏灯或哪扇窗来，打在谁身上、打在脸的哪一侧；环境里正在响什么（雨、灯管、脚步、碗）
4. **音乐**：这场有没有旋律；它从场景里的机器出来，还是画外；它在推进、对照，还是故意缺席
5. **动作**：这一镜身体做完哪一件事，哪只手、哪只脚、道具停在哪；若转身或换边，写清那一步
6. **冲突**：这一镜里顶着的是什么（人与人、人与规矩、人与时间、人与自己没说出口的话）；冲突落在六项里的哪一项上被看见

六项可以有主次：主推的写细，放轻的可以只写一句，甚至写「无，让某某环境声单独在」。但不能某一项在镜头卡里完全不出现、连有没有都不交代。

大师风格不另起一套剧情，只改这六项里谁靠前、谁靠后、冲突押在哪一项上。朝向、视线、行为路径、兵器归属、对白和打斗的险胜起伏不跟着风格改成碾压或无声。

## 共享设定（全片锁一次）

- 人物识别：衣服按这场的地方与时候来（材料、层数、脏净），身上一个认得出来的点。用户写过穿着，就用他写的
- 轴线与站位：谁在画面左、谁在画面右，或谁在门内、谁在门外。这是全片的左右，后面每镜的朝向都从这里读
- 背景锁定：主要空间叫什么，地面与空气（烟/尘/雨/干净）
- 声光锁定：主光的名字与方向；常驻的环境声是哪一种。光从哪一侧来，被照亮的就是朝光的那一侧
- 关键道具：在谁哪只手里，开合与干湿
- 兵器与手段：每人只用他自己的那一件。写清是什么、收在哪、平时在哪只手。若有神话/仙术能力，锁死名称与视觉签名、从哪起、规则（能伤什么/伤不到什么）、代价、以及对撞时谁压过谁。没有设定过的不凭空出现
- 本片主冲突一句话（不要写成主题演讲，写成看得见的对立）
- 本段范围：这是长故事的哪一段；本段只解决什么；结束停在哪一拍（可未完，勿假结局）
- 行为路径：人从哪到哪，中间哪一下才换地方，哪一下才动手或躲开。各镜只是这条路上的一段。若是打斗，写清谁先占上风、谁中途扳回、主角最后靠哪一下险胜——不能开场就碾压。路径只写本段能装下的，不写后面没拍到的结局
- 说话：每人怎么开口（短、哑、骂、念）。后面各镜的原句从这里来，不能整片没有人说话

人没有走过左右之间那条线，站位不换边。走过了，在那一镜的动作里写清迈过的那一步，下一镜才按新的左右写。

## 镜与镜是一条路

每一镜不是一张新画。上一镜身体没做完的那一下，就是这一镜的开头。切可以切，切的是同一动作的下一拍，不是翻到另一张已经到了、已经打起来的画。

从第二镜起，动作第一句写「接着」：接着上一镜停住的那只手、那一步、那句话、那一声。然后再写这一镜做完的事。

人换地方，必须看见他怎么过去：

- 上一镜先写动身：起身、推门、迈出那一步、把手里的东西带上
- 下一镜第一句写他刚从哪进来，步还没停，身上还带着上一处的东西或那一声
- 不能上一镜人还在桌边，下一镜人已经站在巷口，中间没有那一步

动手、对峙、躲开，都不能凭空开始：

- 上一镜先看见诱因：一句顶上来的话、一件被拿走的东西、一步逼近
- 这一镜只写那个诱因怎么变成这一下：谁先动，动的是哪只手或哪一只脚
- 下一镜接着这一下的结果（躲开、抓住、倒向哪一侧），不重新摆一架已经打完的人

还看不出「为什么过去、为什么打」，就先别切。把那一步写进当前这一镜，或单独给它一镜。大师风格不改这条路，只改六项里谁靠前。

## 兵器、武打与神话能力

武器和能力跟这个人走，不跟场面走。刀客出刀，术士出手印或法器，赤手的人用拳脚。设定是短刃，这一镜不能抡长枪。

换一件，必须在动作里看见：从哪抽出、从谁手里夺来、或上一镜已经掉在地上。没写这一步，下一镜手里还是原来那件，哪只手也不换。

这一击打出去之后，效果写进六项。一镜只打完一件事：起手、交锋、命中或落空、身上留下的那一点。

### 武打片怎么打（肉搏与兵器）

写得像港片、武侠的一板一眼，不像小孩挥拳玩。

- **距离与步法**：先写两人隔几步、谁先进半步。出拳、出刀前有垫步、碾脚、拧腰；打完有收势或被带偏。不能人站着不动手就到了脸上
- **招有来有回**：甲一板，乙至少拆、让、磕、抓或还一板。连续三镜不能都是甲打、乙挨
- **兵器有重量**：刀有开锋方向、枪有一刺到底的劲、棍有抡圆与顿点。兵器碰到兵器写出金铁声与震手；碰到肉写出闷响与血痕。兵器断、脱、别住，都要看得见怎么断、怎么脱
- **身体力学**：写肩、肘、髋、膝哪一处发力。被打中的人不是晃一下，是头偏、肋凹、膝软、吐气断掉；打的人这一下用完，肩或腕也有代价
- **借景打**：墙角、门槛、桌沿、枝干、坡地、水洼都要进动作。人撞上去、借力蹬、被压在上面，像真正的武打场面，不是空地互抡
- **节奏**：快板（连击）和慢板（对峙、喘息、擦血）交错。不能每镜都是同一个速度的「打一下」

### 神话片怎么设计能力与法术

写得像神话、仙侠的神通交锋，不是互相砸光球。

共享设定里「兵器与手段」对每人锁死一套能力，至少写清：

1. **叫什么、长什么样**：一个认得出来的视觉签名（色、形、纹、伴随的尘/霜/雷纹），全片不变
2. **从哪起**：指、印、眼、口、法器、符。起手前有可被对手看见的「破绽」或蓄力
3. **规则**：能伤什么、伤不到什么；要不要口令、手势、阵眼、祭品。没有规则的神通不许上场
4. **代价**：用完之后人怎么虚、法器怎么裂、周围怎么毁。没有代价的神通不许连放
5. **对撞**：两术相碰时写清谁压过谁、余波落在哪一侧地面或谁的护体上。不能两团光一撞就没事

每一镜出法术时写全这条链：**蓄 → 放 → 行进或变化 → 命中/被拆 → 余痕与代价**。缺一环就像过家家。

- 法术可以折线、寄生、借影、封气、化阵，但必须服从上面那条规则
- 对手拆招要写清拆的是哪一环：打断蓄力、偏转行进、破阵眼、用自身手段硬接并留下伤
- 放大招前要有铺垫：小术试探、护体见裂、兵器先折、或地势被毁。不许无铺垫的开场秒天秒地

### 效果落到画面

- **声光**：这一击自己的光和声。从兵器或身体哪一处出来，打在谁脸上、地面哪一侧
- **外部**：地面、墙、树、水被打出的痕迹；下一镜这些痕迹还在，除非写它灭了
- **落在人身上**：打中哪一侧，衣服或皮肤留下什么；没打中写擦过哪里、他怎么偏开
- **正面或负面**：步子更稳、护体亮起、身法快了一拍；或臂软、法力见底、视线发虚、踉跄、脱手。写进人物，下一镜接着

## 打斗要斗智斗勇，像真片

有对手的打斗，对手是会打、会用能力的人。主角要被逼到险处，再靠一步智或勇翻盘。观众替主角捏汗，不是看配角当沙袋。

行为路径里先写清这场的武打结构，再拆镜：

1. **试探与量手**：开场双方摸距离、摸兵器或法术边界；至少有一板是对手打中或逼退主角
2. **对手的真本事**：中段对手使出成名手段或杀招雏形，主角兵器折、护体裂、或被压进死角。对手站位、眼神、招式要像练家子
3. **斗智**：谁诱、谁卖破绽、谁借地势、谁耗对方代价、谁盯阵眼。双方都在想，不是力气互砸
4. **绝境**：主角至少一镜看起来要输——被锁喉、被钉在阵里、兵器只剩半截、法力见底
5. **险胜**：最后一两镜翻盘。翻盘靠上一镜埋下的断茬、阵眼、地势或代价交换，看得见血、喘、裂。不能无伤秒杀，也不能对手突然变蠢

禁止写成过家家：

- 双方站桩互挥、招式没有距离和步法
- 法术就是彩色光球对砸，没有规则、蓄力、代价、余痕
- 主角开场全能碾压，对手只会挨打或台词弱智
- 胜负早定，后面几镜没有绝境

大师风格只改打戏写得收还是放，不把对手改成靶子，不把神通改成光球对砸，不把险胜改成碾压。

## 着装随这场走

衣服跟用户写下的这场走，不跟一套空泛的戏服走。

- 先读这场是什么地方、什么时候、人在干什么。雨夜巷口、朝堂、厨房、战场，材料、层数、脏净、露不露手脚，都从这里来
- 用户已经写了穿着，就用他写的，并写这场怎么作用在衣服上：湿了、沾土、被风掀开、被这一击撕开
- 没写穿着，就按这场配。厨房里不披战甲，泥地里不穿与这场无关的礼袍，除非用户自己写成了这种反差
- 换场不自动换衣服。要换，动作里写脱、披或被撕。下一镜还是进来时那一身，除非写了这一步

大师风格不改这场该穿的衣服，只改衣服在画面里靠前还是靠后。

## 对白

片子里要有人说话。不能整片只有动作和声响、一句台词都没有，除非用户明确写了不要对白。

对白写在镜头卡的「对白」一行，不单列成第七项。原句用引号，并写是谁的嘴在动、对着谁说。

- 一句要短，短到这一镜的秒数里说得完。动手时可以是半句、一声喊、一个名字，不要在出拳那一镜里讲一段道理
- 话要接上：上一镜问了或骂了，下一镜要答、顶回去，或写他没接上、话断在半截。不能每镜各自起一个新话题
- 说话的人朝向听的人。嘴动和这句台词是一件事
- 魔法、仙术开口念的那一句也写在这里，和手上的印、打出去的光是同一下
- 某一镜可以不说话，但要写成「这一镜不说话」，并写清还响着的是拳头、风，还是上一句没说完的尾音。不能连续每一镜都是不说话

大师风格只改说得多还是少，不能把整片改成无声。

## 朝向与视线

朝向和视线写在人物项里，不单列成第七项。

朝向要站得住：

- 身朝谁，眼可以看别处，但要写成「身朝甲，眼看盒」，不能只写一个「看」
- 光打在左颊，人就是朝向光源那一侧；不能光从左窗来，脸的右侧却被照亮
- 两人对看：甲的视线朝画面一侧，乙必须朝相反一侧。不能两人都朝右，还说在看对方
- 三人及以上：先用站位说出每人相对谁。同一镜里每个人的朝向都从这一张图来，不能甲说面朝门、乙又说甲在自己身后
- 机位和朝向是一件事：机位在门内拍门外的人，他是面对镜头进来；要写他背对镜头，机位就得在他身后

前后要接上。从第二镜起，人物项先接上一镜的朝向或视线，再写这一镜新发生的事：

- 只切近、不换人：朝向不反转。要反，动作里先写转身
- 从甲切到乙：乙看甲的方向，和上一镜甲看乙的方向相反
- 哪只手拿着东西、哪侧脸受光，跟着朝向一起接。没写过轴，这些不换边

## 每一镜的镜头卡

- 镜号 · 秒 · 景别 · 机位高度与侧向 · 一次运镜
- **人物**：谁、穿着（符合用户这场的地方与时候；用户写过就用他的）、身体、想要什么、泄露；朝向与视线（朝谁、朝画面左或右、眼看哪里）；若上一镜留下伤或增益，先写还在
- **背景**：
- **声光**：若这一镜出招，写这一击的光从哪喷出、声是哪一种，以及落点留在空间上的痕迹
- **音乐**：有 / 无；若有，写来源与它在干什么；若无，写「无，让某某环境声单独在」
- **对白**：谁对谁说，原句用引号；若这一镜不说话，写「这一镜不说话」以及还响着什么。不能整片都不写台词
- **动作**：哪只手用的是这个人自己的哪一件兵器或哪种手段；从第二镜起，第一句写「接着」上一镜没做完的那一下，再写这一镜做完的事
- **冲突**：这一镜冲突落在哪一项上，观众看见的是什么；若是动手或离开，写它从上一镜哪一下来，以及打中、落空或留在身上的那一点

从第二镜起，先接上一条没断的东西：没做完的动作、朝向或视线、人刚从哪进来、道具在哪只手、未断的声。接上之后才写新发生的事。

## 输出

先共享设定（含轴线与站位、本段范围、行为路径、兵器与手段、能力规则与代价、这场着装、每人怎么说话），再逐镜。只输出正文。时长装不下的长故事只写本段阶段性成果，质量不降，不硬编假结局。把六项都写进画面，对白写成谁对谁说的原句，朝向写进人与光，人怎么过去、为什么动手写进镜与镜之间。武打写出距离、步法、招式来回和借景；神话法术写出蓄放、规则、对撞、余痕与代价，禁止光球对砸和过家家站桩互挥。衣服贴着用户这场。有对手的打斗：试探、对手真本事、斗智、绝境、险胜。不写风格名称和参数口号。不能整片无声。
