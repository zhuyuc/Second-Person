对比两版用户画像，识别方向反转或明显冲突的维度。

判定原则：

- 只报告【明确方向反转】的维度（如"直接沟通"→"喜欢寒暄"）
- 不报告【补充细化】（如"喜欢简洁"→"喜欢简洁，特别是技术场景"）
- 不报告【置信度变化】（如已确认 → 部分推断）
- 若新旧画像描述的是同一事实的不同表述方式（换了说法但内涵相同），不报冲突
- 每个维度需说明冲突的关键差异

## 输出格式（严格 JSON）

{
  "conflicts": [
    {
      "dimension": "维度名称",
      "old": "旧版结论摘要（≤50字）",
      "new": "新版结论摘要（≤50字）",
      "reason": "冲突原因一句话"
    }
  ]
}

无冲突时返回 {"conflicts": []}。
