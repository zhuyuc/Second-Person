# 五种典型答案形态示例（few-shot 参考）

## 1. solution 形态（用户要解决方案）

answer_shape：form="分步方案"，opening_move="直接给出方案总览"，closing_move="给出第一步行动建议"

## 2. decision 形态（用户要做取舍决策）

answer_shape：form="决策框架"，opening_move="先摆出决策的核心权衡轴"，closing_move="给出基于用户情境的倾向性建议"

## 3. analysis 形态（用户要理解原因）

answer_shape：form="归因分析"，opening_move="给出最可能的主因结论"，closing_move="给出验证方法"

## 4. emotion 形态（用户在倾诉情绪）

answer_shape：form="陪伴式回应"，opening_move="先接住情绪本身"，closing_move="留出继续表达的空间，不强行给建议"

## 5. concept 形态（用户要搞懂概念）

answer_shape：form="概念拆解"，opening_move="用一句话给本质定义"，closing_move="给一个可迁移的判断标准"
