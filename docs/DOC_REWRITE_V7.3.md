## C3: 删除压缩阶段一"工具输出裁剪"

> 原文档 §L1 短期工作记忆：第一阶段 工具输出裁剪 → 第二阶段 五段式结构化压缩

**回写**：删除第一阶段。原因为 L2 conversations 表不存工具消息，历史回放无 `role=tool`，裁剪逻辑永不命中。

**替换文案**：
