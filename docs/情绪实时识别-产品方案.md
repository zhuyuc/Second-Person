# 情绪全流程 · 产品方案

> Second Person · 双源情绪：产生 → 维持 → 表达 → 消退 → 沉淀  
> 硬约束：**不伤回复质量、不伤前缀缓存；速度仅允许受控的 pre-turn 开销**  
> 快路径模型（暂定）：**DeepSeek Flash**（**仅本调用**关思考、极简 JSON）  
> 日期：2026-09-22

## 产品一句话

用户本句情绪在回复前由 **DeepSeek Flash** 做极简结构化判定，写入 `context.mood`（仅 messages 尾部）；主模型只生成回复；回合结束后完成 AI 情绪校正、融合/传染、平复与回落并落库；闲时按半衰期惰性衰减。词典与规则通道作降级与硬信号。

| 项 | 定案 |
| --- | --- |
| 本轮用户情绪 | Pre-turn DeepSeek Flash（**仅该次调用**关思考 + 极简 JSON）；超时/低置信 → 词典 → 库内态 |
| 主生成 | `agent_step` 纯回复（槽位思考开关**不受**情绪快路径影响） |
| 真值落库 | After-turn：`mood.judge` → `apply_v2`（融合 → 传染 → 平复 → 落库）→ `natural_decline` |
| 时间消退 | 读取时惰性衰减（`mood_decay_hours`） |
| 注入 | `mood_rules` → system 静态；状态/约束 → messages 尾部 |
| 观测 | 同轮单条 `agent.turn`：`mood.fast` / `mood.judge` |

---

## 0. 硬约束（全流程适用）

| 约束 | 做法 |
| --- | --- |
| 回复质量 | 主生成不混写 mood JSON；判定失败不污染正文 |
| 前缀缓存 | 可变情绪只进 `context.mood` / `constraints`；`mood_rules` 跨轮不变 |
| 回复速度 | **仅** pre-turn Flash 可阻塞首字，硬超时默认 **800ms**；衰减/传染/平复/回落/模式提取全部 after-turn 或调度，零阻塞首字 |
| 快路径调用形态 | **仅 `mood.fast` 这一次请求**关闭思考；输出 **仅** 紧凑 JSON |
| 槽位隔离（防误伤） | 关思考**不得**写进 `chat` / `agent` / `retriever_refine` 等槽位默认配置，也不得改 Provider 全局 `extra_body`；即使复用同一 Flash 的 `ProviderSnapshot`，也只在 `llm.chat(..., source="mood_fast", extra_body={thinking_enabled: false})` **单次传参** |

## 1. 生命周期总览

```
产生                     维持              表达              消退              沉淀
────                     ────              ────              ────              ────
用户脉冲(Flash 极简JSON) apply 融合        mood_rules        惰性时间衰减      mood_history
规则触发(triggers)       传染              context.mood      自然回落          mood_pattern
AI 经历(after-turn)      归因              主动行为/寒暄策略  平复事件          （周任务）
```

| 阶段 | 何时执行 | 是否挡首字 | 是否改 system 前缀 |
| --- | --- | --- | --- |
| 产生：用户脉冲 | pre-turn | 是（≤ timeout） | 否 |
| 产生：规则触发 | turn 内写库 | 否 | 否 |
| 产生：AI 判定 | after-turn | 否 | 否 |
| 维持：融合/传染/归因 | after-turn | 否 | 否 |
| 表达：注入/行为 | 组装 prompt | 否（读库+融合，CPU） | 否 |
| 消退：时间衰减 | 每次读取惰性算 | 否 | 否 |
| 消退：自然回落/平复 | after-turn | 否 | 否 |
| 沉淀：模式记忆 | 调度周任务 | 否 | 否 |

## 2. 架构

```
用户消息
    │
    ├─► 规则触发 record（可选，纯写库）
    │
    ▼
DeepSeek Flash（thinking off + json_mode）
    ──超时/低置信/解析失败──► 词典
    │
    ▼
衰减后的 mood_state ⊕ 本轮脉冲 → D（仅本轮展示）
    │
    ├─► context.mood / constraints
    │
    ▼
agent_step（纯回复）
    │
    ▼
after-turn（不挡用户）
    mood.judge → apply_v2(融合→传染→平复) → mood_state
    → natural_decline
```

| 角色 | 组件 | 职责 |
| --- | --- | --- |
| 快路径 | `mood_fast` 槽（未配回退 agent→chat） | 本句用户 → 极简 JSON；仅本调用 `thinking_enabled=false`，换模型只改槽位绑定 |
| 降级 | `mood_fast_signal` | 词典/标点 |
| 触发 | `MoodTriggerRecorder` | 赞踩、重复失败等硬事件 |
| 融合注入 | `MoodManager.build_state_context` | `S ⊕ P → D` |
| 主动行为 | `MoodActionDispatcher` | 按融合态生成本轮约束 |
| 寒暄 | `mood_turn_policy` | 压档、禁复盘 |
| 主对话 | `agent_step` | 可见回复 |
| 慢路径 | `mood.judge` + `apply_v2` + `natural_decline` | AI 情绪、真值、消退加速 |
| 沉淀 | `mood_pattern_extractor` | 周任务写模式记忆 |
| 宿主 | `AgentCore` / `TurnRuntime` | 编排与后台任务 |

## 3. 单轮时序

| 步骤 | 谁 | 做什么 |
| --- | --- | --- |
| T0 | 前端 | `POST /api/chat/send` |
| T1 | 宿主 | `turn_started`；快路径开则 pre-turn |
| T2 | Flash | 用户本句 → 关思考 + `json_mode` → 极简三字段 |
| T2' | 降级 | 超时/错误/低置信/非法 JSON → 词典 → 或仅 `S` |
| T3 | MoodManager | 读库并惰性衰减 → 与脉冲融合为 `D` → `context.mood`；非寒暄则主动行为 |
| T4 | 组装 | system 静态 rules；尾部 mood/constraints |
| T5 | 对话模型 | `agent_step` |
| T6 | 宿主 | 落库回复；带出 `langfuse_trace_id` |
| T7 | 后台 | triggers 摘要 → `mood.judge` → `apply_v2(..., peace_event)` → `natural_decline` |
| T8 | 下一轮 | 以落库态为 `S`，重复 |

约定：Pre-turn 阻塞生成但硬超时；after-turn 不阻塞已发出回复；寒暄走压档并跳过主动行为。

## 4. 产生

### 4.1 用户脉冲（本轮、可挡首字）

**模型槽：** 设置页 **情绪快路径模型**（`mood_fast`）。解析顺序：`mood_fast` → `agent` → `chat`。换模型只改槽位绑定，不必改代码。  

**调用约束（仅作用于 `source="mood_fast"` 这一次）：**

| 项 | 定案 |
| --- | --- |
| 思考 | **本调用关闭**：`extra_body={"thinking_enabled": False}`（或本次 `reasoning_effort="off"`） |
| 作用域 | **禁止**把关思考写进任何槽位默认配置；`agent_step`、精筛、标题、after-turn 等其它调用保持各自原有思考策略 |
| 输出模式 | `json_mode=True` |
| max tokens | 尽量小（仅够三字段，建议 ≤64） |
| temperature | 低（建议 0～0.2） |
| 超时 | `mood_fast_path_timeout_ms`（默认 800） |

**Prompt 要求：** system 极短；只要求输出下方 JSON；**禁止** `note`、解释、markdown、代码围栏、中文标签。

**合法输出（唯一允许形态，对齐 Jev 式决策结果）：**

```json
{"mood":"angry","intensity":0.82,"confidence":0.91}
```

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `mood` | string | 英文白名单标签（含 `neutral`） |
| `intensity` | number | `[0, 1]`，对应 Jev Score 归一后的强度 |
| `confidence` | number | `[0, 1]` |

归一后内部结构：

```text
{ mood, intensity, confidence, source: "flash" | "lexicon" | "state" }
```

非法键、缺字段、非 JSON → 视为失败，走词典降级。

### 4.2 规则触发（不挡首字）

写入 `mood_triggers`，供 after-turn 摘要，不发起 LLM：

- 用户赞 / 踩（挂助手 `message_id`；摘要窗口含近期未消费事件）
- 任务重复失败、久别归来等（有信号则 record）

### 4.3 AI 情绪（after-turn）

`mood.judge` 输入：用户本句 + 助手全文 + triggers 摘要 → 输出 user/ai 双源（含 attribution）→ 进入 `apply_v2`。  
慢路径可继续用同一 Flash 模型；是否关思考由 **`mood_judge` 单次调用**自行决定，同样**不得**改槽位默认。本方案「强制关思考」仅约束 **pre-turn `mood_fast`**。

---

## 5. 本轮表达用融合（展示态，不落库）

- `S`：库内用户态，读取时已按半衰期惰性衰减  
- `P`：本轮脉冲  
- `D`：注入用展示态  

规则：

1. `P.confidence < mood_fast_path_min_confidence` → `D = S`  
2. `P` 强度明显高于 `S` → 标签取 `P`，`intensity = max(S, P)`  
3. `P` 近中性而 `S` 仍高 → `intensity = β·P + (1-β)·S`（惯性）  
4. AI 注入本轮只用库内 AI 衰减态  
5. `D` 不写 `mood_state`  

主动行为与寒暄均基于 `D` + 库内 AI 态。

---

## 6. 维持（落库真值，after-turn）

`apply_v2` 顺序：

1. **融合**：新旧强度按置信度与时间窗口平滑；fresh 为 neutral 时旧情绪向基线回落、不硬盖标签  
2. **传染**：强度 ≥ 0.4 才传染；正面可双向；负面仅 attribution 为 `self`/`shared`；`CONTAGION_BLOCKED` + `other` 不传染  
3. **平复**（见 §7.3）  
4. **落库** `mood_state`；有变化则写 `mood_history`

归因：`none` / `self` / `other` / `shared`，写入状态并影响传染与注入提示。

---

## 7. 消退

### 7.1 时间衰减（惰性，读时计算）

\[
I_{\mathrm{eff}} = I \times 0.5^{dt / \mathrm{mood\_decay\_hours}}
\]

有效强度低于地板值（实现常量）视为 `neutral`，不注入。不跑定时 tick，不挡首字。

### 7.2 自然回落（after-turn）

`natural_decline(session_id)`：近窗连续中性、且无新 triggers 时，强度再乘 `NATURAL_DECLINE_FACTOR`。接在 `apply_v2` 之后，异步执行。

### 7.3 平复事件（after-turn）

`peace_event` 由 after-turn 判定给出（或规则触发提示），传入 `apply_v2`：

| 事件 | 效果（负面侧） |
| --- | --- |
| `user_apology` | 强度 × 平复因子；AI → relieved |
| `ai_admission` | 强度 × 平复因子；用户 → relieved |
| `mutual_reconciliation` | 强度 × 平复因子；→ warm |
| `task_celebration` | 强度 × 平复因子；→ pleased / warm |
| `misunderstanding_resolved` | 强度 × 平复因子；→ relieved |
| `none` | 不平复 |

平复只改落库真值，影响**下一轮**注入；不在 pre-turn 加第二次模型调用。

### 7.4 回到平静

衰减或回落后强度过低 → 标签按 neutral 处理；注入走基线温度描述（若有）。

## 8. 表达

| 通道 | 内容 | 位置 |
| --- | --- | --- |
| 稳定规则 | 表达幅度、与人格优先级、寒暄例外 | system：`mood_rules` |
| 状态快照 | 中文标签 + 高/中/低档 + 归因提示 | 尾部：`context.mood` |
| 主动行为 | 安抚 / 澄清 / 庆祝等 | 尾部：`constraints` |
| 寒暄策略 | 压档、禁止歉意开场 | 尾部约束 + 展示弱化 |

主模型不输出情绪结构字段。

---

## 9. 沉淀

- `mood_history`：每次真值变化留痕  
- 周任务 `mood_pattern_extract`：窗口内高频情绪 → `mood_pattern` 记忆（调度执行，不进对话热路径）

---

## 10. Prompt 与缓存

| 块 | 位置 | 随本句变 |
| --- | --- | --- |
| `mood_rules.md` | system 前缀 | 否 |
| `context.mood` | messages 尾 | 是 |
| `context.constraints` | messages 尾 | 是 |
| 快路径 / judge 请求 | 各自 LLM 调用 | 不进 agent 对话前缀 |

生命周期各阶段写库或改尾部，**不得**改写 agent system 前缀字节。

快路径专用 prompt（示意，实现时落独立短文件）：只含白名单标签说明 +「只输出一行 JSON，三字段，无其它内容」。

## 11. 配置

| Key | 默认 | 说明 |
| --- | --- | --- |
| `mood_enabled` | true | 总开关 |
| `mood_influence_strength` | 0.5 | 注入浓度；0 则不注入 |
| `mood_actions_enabled` | true | 主动行为 |
| `mood_decay_hours` | 2.0 | 时间衰减半衰期（小时） |
| `mood_fast_path_enabled` | true | Pre-turn 快路径 |
| `mood_fast_path_provider` | `flash` | `flash` \| `lexicon` |
| `mood_fast_path_timeout_ms` | 800 | Flash 硬超时（ms） |
| `mood_fast_path_min_confidence` | 0.55 | 低于此忽略脉冲 |
| `mood_fast_path_thinking` | false | **仅 mood_fast 单次调用**为 false；不写回其它槽位 |

传染因子、平复倍率、自然回落阈值、模式窗口等放 `soul/_mood_constants.py`。

## 12. 观测（Langfuse）

同轮仅一条 `agent.turn`。

| 节点 | 时机 | 内容 |
| --- | --- | --- |
| `mood.fast` | pre-turn | mood / intensity / confidence / source / latency_ms / thinking=off |
| `llm.mood_fast` | 于 `mood.fast` 下 | source=`mood_fast`；极简 JSON |
| `mood.judge` | after-turn | 含 peace_event、双源结果 |
| `llm.mood_judge` | after-turn | source=`mood_judge` |

## 13. 降级

| 情况 | 行为 |
| --- | --- |
| Flash 超时/不可用/非 JSON | 词典 → 融合 → 生成 |
| 脉冲低置信 | 用库内 `S` |
| `mood_enabled=false` | 跳过注入与判定 |
| after-turn 失败 | 本轮回复不变；真值保持上一成功态 |
| 无 peace / 无回落条件 | 仅时间衰减 + 常规融合 |

情绪失败不得导致对话 500。

---

## 14. 交付顺序

| 阶段 | 内容 |
| --- | --- |
| 1 | 词典快路径 + 惯性融合注入 + 主动行为吃 `D` + `mood.fast` |
| 2 | Flash pre-turn：单次关思考（不改槽位默认）、`json_mode`、极简三字段、超时降级、延迟实测 |
| 3 | after-turn：`apply_v2` 含 peace_event；`natural_decline`；triggers 摘要窗口 |
| 4 | 周任务模式沉淀核对；历史与衰减验收 |

## 15. 验收

| # | 场景 | 期望 |
| --- | --- | --- |
| 1 | 「气死了！！又全毁了」 | 本轮注入用户负面高档；回复承接 |
| 2 | 库内愤怒，本句「嗯」 | 强度不完全归零（惯性） |
| 3 | 「你好」 | 寒暄压档；不复盘失误 |
| 4 | 两小时无互动后再聊 | 强度按半衰期明显下降 |
| 5 | 连续多轮中性且无触发 | after-turn 后强度额外回落 |
| 6 | 用户道歉 / 和解类回合 | 落库平复后标签或强度骤降；**下一轮**注入体现 |
| 7 | 用户强烈负面 | AI 侧可出现关切类传染（归因允许时） |
| 8 | Flash 超时 | ≤ timeout 开生成；无错误气泡 |
| 9 | 仅情绪尾部变化的连续轮 | system 前缀指纹不变 |
| 10 | Langfuse | 同轮一条 turn；有 `mood.fast`（thinking=off）与 `mood.judge` |
| 11 | 快路径原始输出 | 仅为合法三字段 JSON，无 note/解释/思考块 |
| 12 | 同模型其它槽位 | `agent_step` / 精筛等思考行为与改前一致（关思考未写进槽位配置） |
