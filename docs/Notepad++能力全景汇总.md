# Notepad++ 能力全景汇总

> 调研日期：2026-10-09  
> 依据：官方仓库 [notepad-plus-plus/notepad-plus-plus](https://github.com/notepad-plus-plus/notepad-plus-plus)、Wiki Features、用户手册 v8.x（至约 v8.9.8）  
> 目的：**只盘点 Notepad++ 自身具备的能力**，不做「我们要不要做」的判断。确认取舍时请在本清单上标注。

---

## 使用说明

- 下列每一条均为 N++ **产品能力**（含内置能力；插件生态单独成章）。
- 编号便于后续勾选：可标注 `做` / `不做` / `延后` / `部分做`。
- 「生态」能力（官方插件市场里的第三方）与「内置」分开列出。
